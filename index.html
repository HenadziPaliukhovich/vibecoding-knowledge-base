Чек-лист до 100%

1

Сформулируй идею в одно предложение

5 мин

Без чёткой цели Claude будет угадывать за тебя. Опиши: что делает продукт, для кого и какой результат считается готовым.

  • Одно предложение: «Хочу [что] для [кого], чтобы [результат]»
  • Определи Definition of Done — как ты поймёшь, что готово
2

Установи Claude Code локально

10 мин · один раз

Делается один раз на машине. Дальше — просто запуск claude в папке проекта.

node -v || brew install node
npm install -g @anthropic-ai/claude-code
claude --version
claude   # войти через браузер или задать ANTHROPIC_API_KEY
3

Создай проект и папку

5 мин

Новая папка — новый git-репозиторий. Так проще будет задеплоить в любой момент.

mkdir my-project && cd my-project
git init
claude
/init   # Claude сканирует проект и создаёт стартовый CLAUDE.md
Пустой репозиторий на GitHub понадобится на шаге 7 — можно создать его прямо сейчас на github.com.
4

Опиши задачу и попроси план

Plan mode

Не проси сразу писать код. Сначала — план, который можно поправить до того, как Claude что-то изменит.

# Shift+Tab включает Plan mode
I want to build: [твоё предложение из шага 1].
What's the simplest approach? Create a step-by-step plan
before writing any code.
5

Реализуй с проверкой, а не «на глаз»

Implement

Главное правило: не проси просто «сделай», проси «сделай и проверь». Дай Claude тест, сборку или скриншот как критерий готовности.

Implement the plan. Run the app/tests after each change
and fix failures before moving on. Show me the result
(screenshot or test output) when done.
6

Проверь сам глазами

QA · 5 мин

Даже с автопроверкой всегда открой результат сам. Пройди по ключевым сценариям как реальный пользователь.

  • Открыл и попробовал главный сценарий вручную
  • Нет ошибок в консоли / логах
  • Работает на мобильном размере экрана, если это веб
7

Закоммить и запушь на GitHub

Commit

Попроси у Claude сразу осмысленное сообщение коммита — не оставляй это на «потом».

commit with a descriptive message

# затем в терминале:
git remote add origin https://github.com/USER/REPO.git
git push -u origin main
8

Задеплой и проверь живую ссылку

Deploy

Для статичного сайта — GitHub Pages с автодеплоем на каждый push. В репозитории уже должен быть workflow-файл для этого.

# Settings → Pages → Source: GitHub Actions
# Actions → Deploy GitHub Pages → проверить, что запуск зелёный

# открыть сайт:
# https://USER.github.io/REPO/

100%. Готово задеплоено 🎉

Ты прошёл весь путь от идеи до живой ссылки. Для новой идеи просто сбрось прогресс и начни заново.
