## Rules

1. Read existing code and tests before editing.
2. Ask before adding a dependency or changing a public API.
3. Make one logical change at a time.
4. Add or update tests for changed behavior.
5. Never remove tests or security checks to make the build pass.
6. Never expose credentials, tokens, personal data, or secrets in logs.

## Definition of done

- [ ] Acceptance criteria met
- [ ] Tests added or updated
- [ ] Tests, lint, and build pass
- [ ] Errors and edge cases handled
- [ ] Short change summary provided
